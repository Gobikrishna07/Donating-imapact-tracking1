# Donation Impact Tracker

A donation impact tracking platform concept focused on transparent giving and clear updates about how contributions are used.

## Mock UX Design

[Open the interactive Mock UX](https://gobikrishna07.github.io/Donating-imapact-tracking1/)

This clickable prototype demonstrates the donor journey from discovering a cause to following verified project updates, alongside an organization flow for publishing progress. The donation and update interactions are illustrative only; no payments or data are submitted.
